Jolt (fast) Documentation

Jolt is a standalone, zero-dependency Python package installer, virtual environment creator, and PubGrub dependency resolver written in pure Java 21 and compiled ahead-of-time to native machine code via GraalVM Native Image.

Install on Windows (Recommended — GUI Installer)

Download and double-click JoltSetup-x64.exe. No Administrator rights or terminal commands required—it installs to %LOCALAPPDATA%\jolt\bin, adds fast to your User PATH, and registers a standard uninstaller in Windows Settings.

⬇ Download JoltSetup-x64.exe

Alternative: PowerShell One-Liner

irm https://raw.githubusercontent.com/SarthakMitra323/Jolt-Package-Manager/main/install.ps1 | iex

Verify Installation

fast --help

Clean Uninstall

Removes fast.exe and strips its entry from your User PATH cleanly:

irm https://raw.githubusercontent.com/SarthakMitra323/Jolt-Package-Manager/main/uninstall.ps1 | iex

One-Command Project Setup (fast init)

Inside any existing Python project, run fast init. Jolt automatically:

  • Detects an existing .venv or creates a brand-new PEP 405 virtual environment directly (skipping slow ensurepip).
  • Detects requirements.txt (handling comments, nested -r includes, line continuations, and --hash lockfiles).
  • Falls back to pyproject.toml ([project.dependencies]) automatically when requirements.txt is absent.
  • Resolves, downloads, verifies SHA-256, and hardlinks all packages into .venv.
# Auto-detect requirements.txt or pyproject.toml, create .venv, and install
fast init

# Or include optional dependency groups from pyproject.toml
fast init --extra dev
fast init --all-extras

Common Flags

  • -r, --requirement <file> — Install dependencies from requirements.txt or pyproject.toml.
  • --extra <group> — Install an optional dependency group from pyproject.toml (repeatable or comma-separated, e.g. --extra dev,test).
  • --all-extras — Install all [project.optional-dependencies] groups.
  • -p, --venv, --python <path> — Target a specific virtual environment directory.
  • -j, --jobs <n> — Override max parallel HTTP/download concurrency.
  • --no-cache — Force fresh metadata resolution from PyPI.
  • -v, --verbose / -q, --quiet — Print microsecond timing diagnostics or suppress output.

pyproject.toml & Optional Extras

Jolt ships a zero-dependency character-level TOML scanner supporting PEP 621 [project.dependencies] and [project.optional-dependencies] with PEP 685 extra name normalization.

# Install base dependencies only
fast init

# Install base + dev + test optional groups
fast init --extra dev,test

# Install base + every optional group
fast init --all-extras

Atomic fast self-update

Keep your native binary up to date without re-running PowerShell scripts. SelfUpdater checks GitHub's /releases/latest redirect (zero GitHub API rate limits), compares your local binary's SHA-256 against SHA256SUMS.txt, and short-circuits immediately if you are already on the latest build.

Windows Safe Rename-Swap: Because Windows locks running executables against overwrites, Jolt streams the verified update to fast.exe.new, renames the running binary to fast.exe.old, moves fast.exe.new into place (with automatic rollback on error), and cleans up fast.exe.old on the next invocation.

Security Model

  • User-Space Only: Installs exclusively into %LOCALAPPDATA%\jolt\bin. Never modifies System32, Program Files, or HKLM.
  • Cryptographic Integrity: Both install.ps1 and fast self-update enforce TLS 1.2+ and refuse to install if the downloaded binary's SHA-256 differs by even a single bit from SHA256SUMS.txt.
  • Wheel Verification: Every PyPI wheel is SHA-256 verified on-the-fly during streaming inflation before any file is linked into your virtual environment.
  • Zero Persistence Hooks: No background daemons, no Windows services, no scheduled tasks, and no telemetry.

Building from Source

Requires JDK 21+ (and GraalVM 21 for native compilation, or trigger the included .github/workflows/build-native.yml workflow).

# 1. Compile and package build\jolt.jar
New-Item -ItemType Directory -Force -Path build\classes | Out-Null
$sources = (Get-ChildItem -Path src\main\java, src\test\java -Recurse -Filter *.java).FullName
javac -d build\classes $sources
java -cp build\classes dev.jolt.JarPackager build\classes build\jolt.jar

# 2. Build standalone native fast.exe (GraalVM 21)
native-image -O3 -march=compatibility --gc=serial --no-fallback `
  --enable-url-protocols=https,http -R:MinHeapSize=16m -R:MaxHeapSize=512m `
  -cp build\jolt.jar dev.jolt.Main -o build\native\fast
