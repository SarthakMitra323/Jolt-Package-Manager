Under the Hood

Engineered from scratch for zero waste

Every millisecond counts. Jolt replaces Python subprocesses, regex engines, and temp-file copies with low-level systems primitives.

⚡

Zero-Spawn Env Prober

Reads pyvenv.cfg directly to compute Python version, ABI (cp312), and PEP 425 tags—saving 30–40ms per run by never spawning python -c.

🧮

Bitset PubGrub Resolver

Zero-regex PEP 440 & PEP 508 scanners paired with 64-bit VersionBitSet masks for O(1) version-range intersections and parallel HTTP/2 prefetching.

📦

HTTP Range ZIP Reader

Fetches PEP 658 .metadata blobs (~1.5 KB) or reads only the last 64 KB of remote wheels via HTTP Range requests to resolve graphs without downloading wheels.

🔗

Streaming SHA-256 & Hardlinks

Verifies SHA-256 digests on-the-fly during ZIP inflation into a content-addressed cache, then OS-hardlinks files into site-packages with atomic rollback.

🛠️

Built-In venv & init

Creates PEP 405 virtual environments natively without ensurepip, and reads requirements.txt or pyproject.toml (including --extra groups) in one step.

🛡️

Zero-Backdoor Security

Installs strictly in user-space (%LOCALAPPDATA%\jolt\bin), enforces TLS 1.2+, verifies SHA256SUMS.txt, and uses atomic rename-swaps for fast self-update.
